# FitTrack Gym – Gym Membership Manager

## About the Project

FitTrack Gym is an Android application developed using Java in Android Studio. The application is designed to help manage gym membership information through a simple and user-friendly mobile interface.

## Features

- Manage gym membership information.
- Add, view, update, and delete records, according to the implemented functionality.
- Simple and user-friendly interface.
- Android mobile application.

## Technologies Used

- **Language:** Java
- **IDE:** Android Studio
- **Platform:** Android
- **UI Design:** XML
- **Build System:** Gradle

## Installation and Setup

1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open** and choose the project folder.
4. Wait for Gradle synchronization to complete.
5. Connect an Android device or start an emulator.
6. Click **Run** to launch the application.
